# 四路摄像头实时流式传输显示系统

## 系统概述

这是一个基于Python、FFmpeg和PyQt的四路摄像头实时监控系统。系统可以同时连接和显示四个摄像头的实时视频流，支持RTSP等常见流媒体协议。

## 功能特点

- 🎥 支持四路摄像头同时监控
- 🔄 实时视频流显示
- 🎨 美观的PyQt图形界面
- 📝 完整的日志记录
- ⚡ 高效的FFmpeg视频处理
- 🔧 灵活的配置管理
- 🛡️ 完善的错误处理

## 系统要求

### 软件要求
- Python 3.7+
- FFmpeg (必须安装并配置到系统PATH)
- Windows/Linux/macOS操作系统

### 硬件要求
- 支持多线程的CPU
- 足够的内存（建议4GB+）
- 网络摄像头或IP摄像头

## 安装步骤

### 1. 安装Python依赖
```bash
pip install -r requirements.txt
```

### 2. 安装FFmpeg
- **Windows**: 下载FFmpeg Windows版本，解压并将bin目录添加到系统PATH
- **Linux**: `sudo apt-get install ffmpeg`
- **macOS**: `brew install ffmpeg`

### 3. 验证FFmpeg安装
```bash
ffmpeg -version
```

## 配置说明

### 摄像头配置
编辑 `config.json` 文件来配置摄像头信息：

```json
{
  "cameras": [
    {
      "id": 0,
      "name": "摄像头1",
      "url": "rtsp://admin:password@192.168.1.100:554/h264",
      "enabled": true,
      "resolution": "640x480",
      "fps": 30
    }
  ]
}
```

### 支持的摄像头类型
- IP摄像头 (RTSP协议)
- 网络摄像头
- USB摄像头 (需要对应的URL格式)

## 使用方法

### 启动程序
```bash
python main.py
```

### 界面操作
1. **开始监控**: 点击"开始监控"按钮启动所有摄像头
2. **停止监控**: 点击"停止监控"按钮停止所有摄像头
3. **查看日志**: 右侧面板显示运行日志

### 快捷键
- `Ctrl+Q`: 退出程序
- `Ctrl+S`: 开始监控
- `Ctrl+X`: 停止监控

## 故障排除

### 常见问题

#### 1. FFmpeg未找到
**问题**: `ffmpeg: command not found`
**解决**: 确保FFmpeg已安装并添加到系统PATH

#### 2. 摄像头连接失败
**问题**: 无法连接到摄像头
**解决**: 
- 检查摄像头URL是否正确
- 验证网络连接
- 检查用户名密码
- 确认摄像头支持RTSP协议

#### 3. 视频显示卡顿
**问题**: 视频播放不流畅
**解决**:
- 降低分辨率设置
- 减少帧率(FPS)
- 检查网络带宽
- 关闭其他占用带宽的应用

#### 4. 程序崩溃
**问题**: 程序意外退出
**解决**:
- 查看 `camera_stream.log` 日志文件
- 检查系统资源使用情况
- 确认所有依赖库正确安装

### 日志文件
系统运行日志保存在 `camera_stream.log` 文件中，包含详细的运行信息和错误记录。

## 高级配置

### 自定义FFmpeg参数
在 `config.py` 中可以修改FFmpeg命令参数：

```python
# 自定义FFmpeg参数
cmd = [
    'ffmpeg',
    '-i', self.camera_url,
    '-f', 'rawvideo',
    '-pix_fmt', 'rgb24',
    '-vcodec', 'rawvideo',
    '-an',  # 禁用音频
    '-vf', 'scale=640:480',  # 分辨率
    '-r', '30',  # 帧率
    '-'
]
```
